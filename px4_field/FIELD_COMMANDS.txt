 5. 비행 순서
──────────────────────────────────────────────────────────────────────────────
  ① QGC/조종기: Position 모드, Arm, 스틱으로 이륙 → 2.5 m 안정 호버
       창 A 에 nav_state 와 WAIT 가 보인다
  ② [Offboard 버튼] → 창 A: "OFFBOARD 진입" → ENGAGED → 4 s settle → 패턴 자동 시작
       정책이 10 Hz 로 결정, 창 C 히트맵이 흐르기 시작
  ③ 공격: 스위치 up → 노브를 천천히 올림 (또는 창 B: on, t 0.5)
       정책 hover 선언 → FailsafeParams engage → 현재 위치 사수 (창 C 아래 패널 빨강)
  ④ 노브 down / off → 정책 track 복귀 → 최근접점 재접근(2 m) → 패턴 계속
       (반복 가능. 다른 축·크기도 같은 방식)
  ⑤ 인계: [Position 버튼] → 창 A WAIT(안전) → 스틱 착륙 → Disarm
  ⑥ 창 A Ctrl-C → 엔진·px4 정리. 로그 파일명이 창 A 마지막 줄에 찍힌다
