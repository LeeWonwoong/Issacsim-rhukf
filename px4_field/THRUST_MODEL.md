# 추력 모델과 배터리 항 — 실기 (2026-08-04, F1 실측)

대상: 6호기, AUW **1.326 kg**(저울 실측), 4S. 근거 로그 `px4_field/f1_field.ulg`.

---

## 1. 12상태 동역학 안에서 배터리가 있는 자리

상태 `x = [pⁿ, vⁿ, Θ, ωᵇ] ∈ ℝ¹²` 에 대해

```
ṗ = v
v̇ = g·e₃ + (1/m)·R(Θ)·( −T·e₃ − D·vᵇ )
Θ̇ = T(Θ)·ω
ω̇ = I⁻¹·( τ − ω × Iω )
```

여기까지는 표준이고 **배터리가 들어갈 자리가 없다.** 배터리는 12차원 미분방정식
안이 아니라 그 앞단의 **액추에이터 사상**에 있다:

```
[T, τ]ᵀ = Γ(u; V),        u ∈ [0,1]×[−1,1]³
```

F1 이 잰 것이 이 Γ 의 추력 성분이다.

---

## 2. 실측된 추력 사상

```
        T = c_T · V · u_T ,      c_T = 2.6423  N/(V·unit)
```

검증: `u_T = 0.3320`, `V = 14.83 V` → `T = 13.01 N = m·g` ✓

근거 (F1 정지호버 107.4 s, SoC 61%→31%):

| 측정 | 값 |
|---|---|
| 전압 지수 적합 | `u_hover ∝ V^(−1.021)` — 이론 1/V 와 일치 |
| 창 앞20% → 뒤20% | Δu **+2.78%** vs Δ(1/V) **+2.92%** (비 0.95) |
| `u` 시간추세 (보상 전) | **+3.58%** / 창 |
| `u·V/V_ref` 시간추세 | **−0.05%** / 창 ← 드리프트 소멸 |

호버 스로틀 예측식은 이걸 뒤집은 것이다:

```
        u_hover(V) = K / V ,      K = 4.9232 ± 0.0776   (산포 1.6%)
```

## 3. 전압 항을 빼는 것 = V 를 상수로 동결하는 것

```
T = (c_T·V̄)·u_T·(1 + ΔV/V̄) ≈ C_thrust·u_T ,    C_thrust ≡ c_T·V̄
```

- `V̄` = 운용 SoC 밴드의 평균 전압
- `δ_V ≡ ΔV/V̄` = **버리는 항**. "무시"가 아니라 **모델오차로 넘긴다**는 뜻이다.

**따라서 C_thrust 는 운용 밴드에 묶인 값이다.** 밴드를 바꾸면 상수도 바뀐다.

F1 실측 방전곡선 (SoC 구간별):

| SoC | V̄ | C_thrust = 2.6423·V̄ |
|---|---|---|
| 30~35% | 14.583 | 38.53 N |
| 45~50% | 14.859 | 39.26 N |
| 60~65% | 15.140 | 40.00 N |

> ⚠ 현재 값 **C_thrust = 39.18 N 은 SoC 61→31% 밴드(V̄=14.83)의 값**이다.
> 만충에서 바로 뜨는 프로토콜이면 밴드가 위로 올라가 40~41 N 이 된다.
> **내일 F2/F3 로그의 전압으로 V̄ 를 읽어 한 번만 환산한다.** 추가 비행 불필요.

방전 특성: 소모율 **25 %p/분**, 총 비행 **약 4.0분**.
팩 윗부분이 가파르다 — 84→65% 는 19%p 에 0.70 V, 30→65% 는 35%p 에 0.56 V (약 2.3배).
→ **이륙 후 30초는 버린다.**

## 4. 밴드 폭을 얼마로 잡을 것인가

한 스텝 속도 잔차와 NIS:

```
ε_v ≃ Δt·(C_thrust·u_T/m)·δ ,      NIS_v = ε_vᵀ S⁻¹ ε_v  ∝  δ²
```

**NIS 는 δ 에 대해 2차**다. 힘 비율로 커 보여도 NIS 기여는 제곱으로 줄어든다.

| 밴드 폭 | ΔV | C_thrust 변동 δ_V | NIS 기여 | 공격(2.63) 대비 |
|---|---|---|---|---|
| 10%p (24 s) | 0.22 V | 1.5% | 0.024 | 0.9% |
| 20%p (48 s) | 0.44 V | 2.9% | 0.095 | 3.6% |
| **30%p (72 s)** | **0.65 V** | **4.4%** | **0.214** | **8%** |
| 40%p (96 s) | 0.87 V | 5.9% | 0.381 | 14% |

비교용 다른 교란원 (같은 척도):

| 원인 | 힘 오차 | NIS 기여 | 공격 대비 |
|---|---|---|---|
| 온도 15→33°C (공기밀도) | 5.9% | 0.387 | 15% |
| 배터리 전 구간 100→20% | 9.5% | 1.004 | 38% |
| **공격 (s=1.34, ft1.5)** | **15.4%** | **2.63** | 100% |

절대값은 `R = σ_GPS,z² (0.093 m/s)²` 기준이라 지시적이다. 실제 UKF 는 의도적으로
R 을 높게 쓰므로 절대값은 달라지지만 **행 사이 비율은 R 에 무관**하다.

**결론: 밴드 30%p(≈70초) 이내로 운용하면 배터리 항을 빼도 된다.**

## 5. ★ 논문에서의 위치 — 배터리 새그 = 느린 곱셈형 추력 공격

공격을 곱셈형 액추에이터 결함으로 쓰면

```
T_atk = C_thrust·u_T·(1 + δ_a)
```

`δ_V` 와 `δ_a` 가 **수식에서 같은 자리에 같은 형태로** 들어간다. 크기도 같은 자릿수다.
구분되는 것은 **시간 시그니처뿐**이다:

| | 형태 | 시간 규모 | 잔차 모양 |
|---|---|---|---|
| δ_a (공격) | 스텝 | 0.1 s (1 스텝) | 펄스 — t=1~2 스파이크 후 PX4 보상 |
| δ_V (배터리) | 램프 | 수십 초~분 | 준-DC 기준선 이동 |

→ **CUSUM 은 누적기라 δ_V 램프를 그대로 적분해 오탐한다. 4스텝 윈도우
패턴매칭은 펄스와 램프를 형태로 구분한다.** sim 에서 세운 "펄스 vs 누적" 논거가
실제 하드웨어 교란원에서 한 번 더 성립한다.

⚠ 실기 평가에서 CUSUM 이 불리해지는 것이 알고리즘 차이가 아니라 배터리 때문일 수
있다 — **비교할 때는 양쪽에 같은 처리를 적용**해야 공정하다.

δ_V 를 모델오차로 남기는 결정은 기존 sim2real 원칙과 같은 논리다:
**실기에서 못 없애는 항을 sim 에서만 없애지 않는다** (추력-토크 결합항을 뺀 것과 동일).

## 6. 확인된 것 / 안 된 것

**확인됨**
- `MC_BAT_SCALE_EN` 은 이 문제를 못 고친다. `MulticopterRateControl.cpp:250-256`
  에서 스케일이 **발행 직전에** 곱해지므로, 로그/DDS 로 읽는
  `vehicle_thrust_setpoint` 이 곧 믹서 입력이다. u→T 관계는 파라미터와 무관하게
  동일하고, `u_hover(V)` 도 똑같이 올라간다. 이 파라미터가 고정해주는 것은
  **제어기 응답(demand→T)** 이지 **UKF 가 보는 매핑**이 아니다.

**미검증 — 내일 F2 로 확인 가능**
- 토크도 같은 구조 `τ = c_τ·V·u_τ` 인가. F1 은 호버라 토크 여기가 없었다.
  F2 는 토크를 흔들면서 전압도 떨어지므로 바로 확인된다. 맞으면 Γ 전체가 V 에 대해
  1차 동차라 위 식이 4채널로 그대로 확장된다.
- **추력곡선 T(u) 의 기울기.** F1 은 u 가 0.315~0.341 (±4%) 밖에 안 움직여
  적합이 전부 R² < 0.11 로 무의미했다. 나온 것은 호버점을 지나는 **시컨트 하나뿐**이고
  곡선 모양은 미식별이다. `THR_MDL_FAC = 0` 이라 PX4 가 선형화도 하지 않는다.
  → 내일 **수직 추력 스윕 30초**로 확보 (RUN.txt 1-B).
  → 중요한 이유: 공격이 추력 바이어스라 u 가 호버점을 15% 벗어난다. 그 지점에서
    시컨트 모델이 얼마나 틀리는지가 곧 잔차이고, 기동도 같은 오차를 만든다
    = **기동↔공격 aliasing 의 원천**. sim 에서 이미 겪은 문제
    (호버 secant 25.6 vs 국소기울기 41.7, 급기동 구간에 잔차 집중).
