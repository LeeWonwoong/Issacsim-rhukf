 MicroXRCEAgent 자동 기동 — SSH 창마다 켜면 안 되는 이유와 올바른 방법
════════════════════════════════════════════════════════════════════════
  질문: "SSH 로 들어가면 자동으로 켜지게 하고 싶다. 창 여러 개면 간섭 있나?"

  ── 간섭 3가지 ──────────────────────────────────────────
   (1) 포트 충돌
       에이전트는 UDP 8888 을 바인딩한다. 두 번째 인스턴스는 bind 실패로 죽는다.
       → pgrep 가드로 막을 수 있다. 치명적이진 않다.

   (2) 경쟁 조건(race)
       두 창을 동시에 열면 둘 다 pgrep 를 통과한 뒤 둘 다 bind 를 시도한다.
       하나는 실패하고 로그에 에러만 남긴다. 드물지만 현장에서 헷갈린다.

   (3) ★★ SIGHUP — 이게 진짜 위험하다 ★★
       .bashrc 에서 띄우면 에이전트가 **그 SSH 세션의 자식**이 된다.
       그 창을 닫거나 **현장에서 WiFi 가 한 번 끊기면 SIGHUP 으로 같이 죽는다.**
       → 비행 중 ROS2 링크가 통째로 끊긴다. 오프보드 시퀀스가 중단된다.
       "누가 띄운 에이전트인지" 도 모호해져서, 창을 닫을 때마다 도박이 된다.

   (4) 재기동 부작용
       에이전트가 죽었다 살아나면 PX4 의 DDS 엔티티가 다시 등록된다.
       2026-08-06 에 겪은 유령 토픽(vehicle_status_v4)이 이 계열의 문제다.

  ── 권장: systemd 서비스 (터미널과 무관하게 산다) ───────
    경로 확인:   which MicroXRCEAgent

sudo tee /etc/systemd/system/xrce-agent.service > /dev/null <<'EOF'
[Unit]
Description=Micro XRCE-DDS Agent (PX4 uXRCE-DDS bridge)
After=network.target

[Service]
Type=simple
User=quad
Environment=ROS_DOMAIN_ID=0
ExecStart=/usr/local/bin/MicroXRCEAgent udp4 -p 8888
Restart=always
RestartSec=2

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now xrce-agent
systemctl status xrce-agent --no-pager
journalctl -u xrce-agent -f          # 로그 보기

    · ExecStart 경로는 `which MicroXRCEAgent` 결과로 바꿀 것
    · User= 는 젯슨 계정명(quad)
    · Restart=always → 죽어도 2초 뒤 되살아난다
    · 부팅 시 자동 기동 → **배터리 교체 후 젯슨 재부팅에도 알아서 뜬다**
    · SSH 창을 몇 개를 열든 닫든 무관하다

  ── 차선: .bashrc (systemd 를 못 쓸 때만) ───────────────
    반드시 **setsid** 를 붙여 세션에서 떼어내야 SIGHUP 에 안 죽는다.

# ~/.bashrc 맨 아래
pgrep -x MicroXRCEAgent >/dev/null || \
    setsid nohup MicroXRCEAgent udp4 -p 8888 >~/.xrce_agent.log 2>&1 &

    · setsid 없이 nohup 만 쓰면 세션 종료 시 여전히 위험하다
    · 경쟁 조건은 남는다(동시에 두 창을 열지 말 것)
    · 어느 창이 주인인지 모호한 문제도 남는다 → systemd 를 권한다

  ── 확인 ────────────────────────────────────────────────
pgrep -af MicroXRCEAgent          # 딱 1개여야 한다
ss -ulnp | grep 8888              # 8888 을 누가 쥐고 있나

  ⚠ 이미 여러 개가 떠 있으면 전부 죽이고 하나만 남긴다:
pkill -x MicroXRCEAgent && sleep 2 && sudo systemctl start xrce-agent

      (a) ModuleNotFoundError: No module named 'serial'
            pymavlink 는 시리얼을 열 때 pyserial 을 쓴다. 임포트는 되는데

                newgrp dialout          # 로그아웃 없이 현재 세션 적용
