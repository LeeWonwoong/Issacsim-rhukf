========================================================================
 ULOG 회수 절차 — 비행 후 로그 받아오기          (2026-08-10)
========================================================================

ulog 는 두 군데에 있다
------------------------------------------------------------------------
 ① FC(비행컨트롤러) SD카드   ← 전부. 원본. arm→disarm 1회당 파일 1개
                              (SDLOG_MODE=0, 예: log_43, 번호+UTC시각)
 ② 젯슨 ~/px4_field/ulog/    ← 자동 회수된 사본 (비행이름 붙음)
                              예: f1_hover_log43_20260810_142233.ulg

자동 회수 여부
------------------------------------------------------------------------
 · F1, F3 (offboard 스크립트로 날림) → postflight 자동회수 → ②에 있음  ✓
 · F2 오토튠 → 자동 안 됨(autotune_go 가 같은 포트 점유) → SD에만    ✗ 수동
 · --no-fetch 로 껐거나 comp=0 경합으로 실패했으면 → ②에 없을 수 있음


========================================================================
 절차 (젯슨에 SSH 접속해서)
========================================================================

[1] 자동 회수된 게 뭐가 있나 먼저 확인
------------------------------------------------------------------------
    ssh quad@<orin-ip>
    ls -lt ~/px4_field/ulog/          # 이름 붙은 사본들

[2] FC에 실제로 뭐가 있나 전체 목록 (원본 = 진실)
------------------------------------------------------------------------
    cd ~/px4_field
    python3 fetch_ulog.py --list      # id / 크기 / 기록시각(UTC)

    → 여러 번 날렸으면 시각으로 어느 게 F1/F2/F3 몇 번째인지 매칭.

[3] 빠진 것 수동 회수  (특히 F2 오토튠)
------------------------------------------------------------------------
    python3 fetch_ulog.py --id 45 --name f2_autotune_1   # 특정 로그, 이름 붙여
    python3 fetch_ulog.py --last 12                       # 최근 12개 한꺼번에
    python3 fetch_ulog.py --all                           # 전부 (느림)

    저장 위치: ~/px4_field/ulog/<이름>_log<id>_<시각>.ulg

    ⚠ 주의
      · autotune_go.py 와 동시에 돌리지 말 것 (같은 시리얼 포트).
      · comp=0 이 뜨면 = 다른 MAVLink 프로세스가 붙은 것.
            sudo lsof /dev/ttyACM0     → autotune_go / QGC 등 죽일 것
        (스크립트가 일단 comp=1 로 강제는 하지만, 경합이면 다운로드가 멎는다)
      · 전원 분리 전에 받을 것 (파일은 disarm 때 닫힌다. 착륙했으면 OK).
      · Permission denied 면:
            sudo usermod -aG dialout quad   후 로그아웃/로그인 (항구적)
            급하면  sudo chmod 666 /dev/ttyACM0  (재연결하면 풀림, 임시)

        /home/acsl/projects/Issacsim-rhukf/px4_field/ulog/

    (또는 USB 로 복사)
