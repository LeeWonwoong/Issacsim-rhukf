════════════════════════════════════════════════════════════════════════

  이 문서는 **실기체 FC(px4_fmu-v6c)** 에 공격 패치를 올리는 절차다.
  GPU 서버(SITL)는 이미 빌드·검증됐다(2026-08-08). 설계는 ../ATTACK_INJECTION.md.

  ⚠ 대전제: 공격은 **allocator 의 정규화 wrench c[0] 에 가산**한다. UKF 가 읽는
    vehicle_torque_setpoint(상류)는 안 바뀌므로 깨끗 → innovation(NIS) 성립.
    δ 는 정규화값 = 제어권한 대비 비율(N·m 아님).

[4]  파라미터 + VRA 게이트 (지상, QGC)   ★확정 방식 (2026-08-10)
────────────────────────────────────────────────────────────────────────
  ★ 결정: **VRA 를 공격 on/off 게이트로. 크기는 ATK_TQ_MAX 파라미터(고정).**
    · VRA 올리면(aux>0.5) 정확히 ATK_TQ_MAX 크기 공격, 내리면 0. VRA 위치 무관(게이트만).
    · 최종 실험의 확정 밴드값을 ATK_TQ_MAX 에 넣는다(ulog 에 기록돼 재현성 좋음).
    · ⚠ **"노브 없을 때 게이트 on=고정 크기" FC 수정본(2026-08-10)** 이 필요.
      firmware/px4_fmu-v6c_v1.16.2_dds_attack.px4 (md5 아래)가 그 포함본.

  ── ★ 왜 SWC 가 아니라 VRA 인가 ──────────────────────────
    SWC 는 **비행모드 스위치**라, 건드리면 모드가 바뀐다. 그러면:
      · **offboard 도중 SWC 내리면 → 모드 변경 → offboard 이탈**(패턴 중단). ✗
      · F9 는 "offboard 중 공격" 시나리오라 이게 치명적.
    VRA(aux)는 모드를 안 건드린다 → offboard 유지된 채 공격 on/off. ✓  SWC 는 모드로 그대로 둔다.

  ── 지상 파라미터 (QGC) ──────────────────────────────────
        ATK_EN      = 1        ★ 켜야 동작
        ATK_AUX_SW  = 1        VRA 의 aux (게이트). VRA 오른쪽 끝 = 공격 on
                              ※ 내 기체: VRA=CH9=aux1, VRB=CH10=aux2 (AUX Passthrough 기설정)
        ATK_AUX_TQ  = 0        ★ 0 = 노브 없음 → 게이트 on = 고정 크기
        ATK_AUX_TH  = 0
        ATK_TQ_AXIS = 0        0=roll (F9-1) / 1=pitch / 2=yaw
        ATK_TQ_MAX  = 0.05     ★ 토크 공격 크기 = 권한의 5% (여기에 확정 밴드값)
        ATK_TH_MAX  = 0        ★ 토크만 할 땐 0. 추력 공격은 ATK_TH_MAX=값, ATK_TQ_MAX=0
        ATK_SW_THR  = 0.9      ★ 게이트 임계. VRA(노브)라 0.9 → 끝까지 올려야 on (기본 0.5)

  ── VRA → aux 매핑 (내 기체는 이미 돼 있음) ──────────────
    ★ VRA/VRB 가 이미 채널에 실려 있으면 EdgeTX Mixes 불필요.
      내 기체 확인(2026-08-10): QGC Radio → VRA=CH9, VRB=CH10.
      Additional Radio Setup → AUX Passthrough → AUX1=CH9, AUX2=CH10.
      = RC_MAP_AUX1=9, RC_MAP_AUX2=10 이미 설정 → **VRA=aux1, VRB=aux2.**
      → RC_MAP_AUX 안 건드려도 됨.  ATK_AUX_SW=1 로 VRA(aux1) 를 게이트로.
    ★ 검증: MAVLink Console  listener manual_control_setpoint
         VRA 돌릴 때 aux1 이 바뀌나 (내 기체: 왼쪽끝 −0.952 ~ 오른쪽끝 +1.0).
         오른쪽 끝(>0.5)에서 게이트 열림. 비행 전 왼쪽 끝(off)에 두고 시작.
    ⚠ 다른 기체면 aux 번호가 다를 수 있으니 listener 로 확인 후 ATK_AUX_SW 맞출 것.
    ※ VRA 는 노브라 "완전히 올림 = on". 게이트(>0.5)만 넘으면 크기는 ATK_TQ_MAX 고정.

  ── ★ 두 모드 — ATK_AUX_TQ 하나로 전환 (같은 펌웨어, 재빌드 없음) ──
    · 탐색/테스트:  ATK_AUX_TQ = 2  → VRB 가 토크 크기 노브 (라이브 조절)
                    VRA 끝=게이트 on, VRB 돌려 크기 0~ATK_TQ_MAX. param 안 고치고 탐색.
                    (이땐 ATK_TQ_MAX 를 0.3 쯤 크게 잡아 VRB 범위를 넓게)
    · 확정 실험:    ATK_AUX_TQ = 0  → 고정 크기 ATK_TQ_MAX (확정 밴드값). VRB 무관, 재현.
    · 추력을 VRB 로: ATK_AUX_TH = 2 (그러면 ATK_AUX_TQ=0 등으로 토크는 고정/off).
    ★ VRB(aux2, CH10)는 이미 매핑됨. param 만 바꾸면 켜진다.

  ── (참고) 학습 데이터 DDS 주입은 별개 ──────────────────
    Isaac 밴드 재스윕·학습은 online_rl 이 DDS 로 actuator_attack 을 쏜다(RC 무관, GPU
    px4_msgs 이미 됨). 실기에서도 companion 으로 값을 바꿔가며 쏘고 싶으면 [7]+
    rc_attack_trigger 를 쓰면 되지만, **확정값 실험은 위 param 방식이 더 단순·재현적.**
