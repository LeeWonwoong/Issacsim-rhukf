  [부록 A]  왜 1.17.0 이 아니라 1.16.2 인가  (2026-08-06 실물 대조)
════════════════════════════════════════════════════════════════════════

  GPS 10Hz — 둘 다 동일하게 달성된다
    v1.15.4 : rate_meas = (F9P) ? 100 : 125           → M10 은 무조건 8Hz
    v1.16.2 : rate_meas = 100 기본, 예외는 F9P L1L2(200)/F9P L1L5(143) 뿐
              → M10 은 case 가 없어 100ms = 10Hz
    실측 근거(log_25) : utc dt 히스토그램 125ms×2318 / 250ms×389
                        = 정확히 8Hz + 14.4% 에폭 유실

  FLASH ★ 결정적
    현재 v1.15.4+2줄 = 98.85% (1943500 B / 1920 KB), 여유 1%
    DDS 토픽 수   v1.15.4 : 51    v1.16.2 : 51    v1.17.0 : 65
    → 1.16.2 는 지금과 같은 조건. 1.17.0 은 +14 로 넘칠 위험이 크다.

  패치 성숙도
    v1.16.0  2025-08-05
    v1.16.1  2025-09-08
    v1.17.0  2026-01-16   ← .0, 이후 패치 릴리스 없음
    v1.16.2  2026-04-22   ← 1.17.0 이 나온 뒤에도 1.16 라인을 계속 고쳤다
    실기체에 올리는 펌웨어라면 1.16 이 맞다.

  변화량 (1.15.4 기준)
    MC제어기/제어할당   → v1.16.2  77 files +805/−2100
                        → v1.17.0  83 files +1295/−2309
    파라미터 정의       → v1.16.2  76 files
                        → v1.17.0 103 files

  토픽 이름 변경 (우리가 쓰는 12개 중)
    v1.16.2 : vehicle_status → vehicle_status_v1     (1개)
    v1.17.0 : vehicle_status / vehicle_local_position / vehicle_attitude_setpoint (3개)

  포기하는 것
    1.16.2 에는 DRV_GPS_DEVTYPE_UBX_10 매핑이 없어 QGC 가 GPS 를 제네릭
    u-blox 로 표시한다. → `gps status` 의 MOD=/FWVER= 로 확인하면 되므로 실익 없음.

  px4_msgs 정합 (우리가 쓰는 12개 메시지, 필드 단위 대조)
    v1.15.4 ↔ release/1.15  →  12/12 일치
    v1.16.2 ↔ release/1.16  →  12/12 일치
    v1.17.0 ↔ release/1.17  →  12/12 일치
    현재(px4_msgs main ↔ 기체 1.15.4) → SensorGps / VehicleStatus /
      VehicleLocalPosition / VehicleAttitudeSetpoint 4개 불일치.
      특히 VehicleAttitudeSetpoint 는 필드 #1 부터 어긋나며
      offboard_common.py:216 이 실기로 publish 한다 = 이미 깨진 경로였다.

  Pegasus 호환 (검증 완료)
    · 지금 SITL 이 v1.18.0-alpha1 로 정상 동작 중 → 구 버전인 1.16.2 는 안전
    · simulator_mavlink 모듈 : v1.15.4 / v1.16.2 / v1.18-alpha 전부 존재
    · 10016_none_iris, 10015_gazebo-classic_iris : v1.16.2 에 존재, main 과 동일
    · rcS diff (v1.16.2 ↔ main) : param reset 로직뿐, Pegasus 접점 무관
    · 프로젝트가 PX4_PARAM_* / PX4_SIM_MODEL 을 직접 쓰는 곳 없음
    · sim 쪽 소소한 이점: rcS 의 `param set-default MAV_PROTO_VER 2`
      (SITL 재시작 직후 첫 패킷 드롭 방지) 가 1.16.2 엔 있고 1.17.0 엔 없다.
      스윕이 에피소드마다 bin/px4 를 죽였다 살리므로 무관하지 않다.

  ARM 툴체인
    v1.16.2 는 배포판 gcc-arm-none-eabi 를 그대로 쓴다.
    설치본 10.3.1 (2021.07) 로 충분. 별도 설치 불필요.
