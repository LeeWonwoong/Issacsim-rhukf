 1. QGC — FC 파라미터 (전원 후 1회)
──────────────────────────────────────────────────────────────────────────────
  EKF2_RNG_CTRL 2 · EKF2_OF_CTRL 0 · MPC_XY_VEL_MAX 2.0
  ATK_EN 1 · ATK_AUX_SW 1 · ATK_SW_THR 0.9 · ATK_AUX_TQ 0 · ATK_TQ_AXIS 0 · ATK_TH_MAX 0
  ATK_TQ_MAX 0.5            # ★ 공격 크기 δ (VRA 오른쪽 끝 = on). 약하게: 0.3
  # param show ATK_EN 이 떠야 공격 펌웨어. SWC(모드)·SWD(모터종료)는 손대지 않는다.

 2. [L1] 젯슨 — 정책 노드 (오프보드 주행 + NN 실시간 추론)
──────────────────────────────────────────────────────────────────────────────

  cd ~/swirl_field/px4_field; source /opt/ros/humble/setup.bash; source ~/colcon_ws/install/setup.bash
  sudo chmod 666 /dev/ttyACM0                                   # dialout 그룹이면 생략

  # 벤치(프로펠러 없음, 빠른 검증):  아래 명령 뒤에 --bench --no-fetch
  # 첫 소티(결정만 기록):            아래 명령 뒤에 --shadow
  # 본 소티(NN 이 hover 실행):
  python3 f13_policy.py --model $MODEL --pattern circle --attack rc --fs-url /dev/ttyACM0 --atk-aux-tq 0 --atk-tq-max 0.5
  # 패턴: --pattern waypoint | figure8 | aggressive | scurve.  뜨면 "UKF 초기화 …" → WAIT 로 SWB 대기.
  # 끝: 착륙·disarm 뒤 Ctrl-C (ulog 자동 회수). 로그 field_logs/f13_policy_<pattern>_<시각>.csv

──────────────────────────────────────────────────────────────────────────────
 4. 조종기 순서 (각 소티)
──────────────────────────────────────────────────────────────────────────────
  ① 잔디에 놓고 전원 → EKF 수렴 30~60 s → Position 모드 arm → 스틱 이륙 → 2.5 m 안정 호버
  ② SWB ON(오프보드) → L1 "OFFBOARD 진입" → ENGAGED → settle 4 s → 패턴 자동, NN 10 Hz 결정
  ③ 궤적 안정 뒤 VRA 오른쪽 끝(공격 on) 10~20 s → L3 gyro 관측 ↑ → 행동 1(hover), L1 "▶ HOVER (선언 #n)"
  ④ VRA 내림(off) → 행동 0(track), "◀ TRACK 복귀" → 최근접점 재접근 → 패턴 계속
  ⑤ ③④ 2~3회 반복 → 완주 후 DONE_HOLD(제자리 정지)
  ⑥ SWB OFF(Position 인계) → 스틱 착륙 → disarm → L1 Ctrl-C
  ★ 이상 시: VRA 내림 → SWB OFF → 최후 SWD

  벤치(프로펠러 없음)일 때: Stabilized arm → SWB ON → 모터 낮게 회전 → VRA on = 모터 두 개↑두 개↓(공격 경로)
                            + 손으로 10~20° 기울여 유지 = NN hover 선언 확인 → VRA off·수평 → track 복귀
