## 공통 규칙
- **제약:** N ≥ 6 · pΔ 0.01 · B128 우선 · L ∈ {4, 6}
- **망을 바꾸면 Adam 도 같은 망으로 돌린다.** 표준 설정 lr3e-4·β5·clip10·B128 은 그대로 둔다.
- **N 결정:** N·B ≥ P 규칙으로 정한다.
- **q = 5e-3/N:** 창 끝의 실효 사전을 Isaac 확증 G1(N5·q1e-3)과 같게 둔다.
- **α ∝ 1/√P:** P962 에서 0.1 이다. [24]는 0.1 로 반올림했다(L6 은 규칙상 0.093, 7% 차이).
- **K 체제**
  - G1 = R2 (λ200)
  - G2 = R1 (λ100) — B128·[24] 칸에만 둔다.
- **고정:** huber 0 · ui1 · τ0.005 · act=target · spas
- **재사용:** 기준 G1(L4[24] B256 N5)과 Adam L4[24] B128 은 n69 결과를 그대로 쓴다. base·set·시드가 같다.
- 보상은 n69 판정으로 이긴 쪽 판만 돌린다. v5 / r1316 두 판이 모두 준비돼 있다.

## 사전 등록 선택 규칙
**지표**
- **SWIRL F1:** greedy F1 절대값 (eval.json)
- **ΔF1:** 같은 시드·같은 L·망·보상의 Adam 대비 차이. 1316 판은 평균·중앙값·붕괴 제외 평균을 함께 보고하고, Adam 붕괴 시드 수(F1 < 0.60)도 따로 센다.
- **Δret:** 학습 리턴 차이. 전체 0–199 와 후반 100–199 를 본다 (hist.json).
- **탐지기 지표:** event_det · fpr · relapse_per_event · delay · fa_episode_rate

### 단계 0' — 기준 보정 (A 결과를 보기 전에)
- 단계 B 통과 기준을 n69 G1 8시드에 먼저 적용해 본다.
- G1 이 떨어지는 항목이 있으면, 그 항목만 "G1 보다 나쁘지 않음(허용 폭은 G1 시드 표준편차 1개)"으로 바꾼다. 바꾼 내용은 이 파일에 적어 고정한 다음 A 를 판정한다.

### 단계 A
1. **탈락 조건** (하나라도 해당하면 탈락)
   - 어느 시드든 F1 < 0.60, crash > 0, 또는 NaN
   - event_det < n69 G1 − 0.03
   - fpr > n69 G1 × 1.3
   - 평균 ΔF1 ≤ 0 (1316 판은 중앙값 ΔF1 ≤ 0)
   - ΔF1 은 여기서 게이트로만 쓴다.
2. **순위**
   - 1차: SWIRL 절대 F1 (2시드 평균)
   - 2차: Δret 후반
   - 3차: det↑, relapse↓, fpr↓, delay↓
3. **잡음 대역:** 1위와 그 다음 칸의 차이가 0.03 미만이면(약 1.5 SE) 사전 선호 순서로 정한다.
   - L6[24]B128N9 G1 → L4[24]B128N8 G1 → L6[24]B128N9 G2 → L4[24]B128N8 G2 → 큰 망 B256 → L6[24]B256N6 → L4[24]B256N6
   - 근거: B128 을 먼저 둔 것은 사용자 선호다. L6 은 사용자 요청이다. B256 을 쓴다면 파라미터가 큰 쪽을 먼저 둔다. K 는 Isaac 에서 확증된 G1 을 먼저 둔다.
4. **B256 채택:** 가장 좋은 B128 칸보다 SWIRL F1 이 +0.03 이상, 두 시드 모두 앞서고, fpr·relapse 가 나빠지지 않을 때만 B256 을 고른다.
5. **L6 보호:** surrogate k-NN 풀은 4프레임 기반이라 L6 을 과소평가할 수 있다. 그래서 L4 대비 −0.03 안이면 L6 을 살린다.
6. **곁가지:** 채택하지 않는다. 보고만 한다.
7. **진출:** 탈락하지 않은 상위 2칸.
   - **폴백:** 통과한 칸이 없으면 N ≥ 6 칸 가운데 SWIRL F1 최고 칸 하나를 B 로 보내고, n69 G1 대비 격차를 보고한다. N5 인 G1 은 최종안이 될 수 없다.

### 단계 B (칸당 8시드)
- **통과 조건:** 아래를 모두 만족해야 한다.
  - 붕괴 시드 0
  - 평균 ΔF1 > 0, 그리고 8시드 중 7시드 이상 양수 또는 짝 t 검정 p < 0.05 (1316 판은 중앙값 기준도 함께 본다)
  - 평균 ΔFPR ≤ 0
  - relapse ≤ Adam
  - det ≥ Adam − 0.01
  - delay ≤ Adam + 0.5
  - Δret > 0
  - SWIRL 평균 F1 이 표준 B128 모든 망의 Adam 가운데 최고 평균 F1 보다 높음
- **B256 추가 조건:** SWIRL 이 B256 칸이면 같은 망 Adam B256(보고용) 평균 F1 보다도 높아야 한다.
- **반대 보상 판:** 붕괴 0, 평균 ΔF1 > 0.
- **선택:** 통과한 칸 중 SWIRL F1 1위를 고른다. ±0.01 안이면 A 의 선호 순서를 따른다.

### 단계 C (Isaac)
- **실행 조건:** 두 시드 모두 HARD = 0, simclock overrun ≤ 2%, TIMING_LOG 의 learn_ms p90 ≤ 35 ms.
- **통과 조건** (두 시드 모두):
  - 짝 리턴 > 0 (cmp3)
  - 후반 F1 (ep 150–199)에서 SWIRL − Adam > 0
  - 후반 FPR ≤ Adam, relapse ≤ Adam
  - 참조(v14 또는 v15_1316) G1 의 같은 시드보다 후반 F1 이 0.01 넘게 낮지 않음
- **실패 시:** B 통과 칸 가운데 N ≥ 6 차순위로 간다. 그것도 없으면 L4[24] B256 N6 G1 로 돌아간다(A 에 증거가 있다).
- 결론에는 v14 s44 완료 여부를 함께 적는다.
